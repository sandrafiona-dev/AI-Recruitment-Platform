# Project Roadmap

This four-week roadmap establishes the platform foundation, develops the
initial AI capabilities, and prepares the project for demonstration and
deployment. Each week concludes with a review of completed work, risks, and
next priorities.

## Week 1 — Foundation and Data Understanding

| Workstream | Activities | Deliverables |
| --- | --- | --- |
| Project Setup | Establish repository structure, FastAPI backend, React frontend, environment guidance, and documentation. | Runnable project scaffold and development workflow. |
| Dataset Collection | Identify permitted datasets, document sources, assess quality, and define data-handling rules. | Dataset inventory and collection plan. |
| EDA | Profile fields, missing values, distributions, duplicates, and potential bias indicators. | Exploratory data analysis notebook and findings summary. |

## Week 2 — Resume Intelligence and Matching

| Workstream | Activities | Deliverables |
| --- | --- | --- |
| Resume Parsing | Define resume schema, extract relevant information, and validate extraction quality. | Resume parsing workflow and structured output. |
| Classification | Prepare labels and develop an initial resume-classification baseline. | Classification baseline and evaluation metrics. |
| Matching | Define matching features between resumes and job descriptions. | Initial candidate-to-job matching prototype. |

## Week 3 — Prediction and Recommendation

| Workstream | Activities | Deliverables |
| --- | --- | --- |
| Prediction Models | Develop and assess suitable prediction models for approved use cases. | Evaluated prediction-model candidates. |
| Ranking | Implement a transparent candidate-ranking approach with recruiter-review considerations. | Candidate ranking prototype and review criteria. |
| Recommendation System | Develop recommendations based on job, candidate, skill, and historical signals where permitted. | Initial recommendation workflow and documented limitations. |

## Week 4 — Quality, Delivery, and Deployment

| Workstream | Activities | Deliverables |
| --- | --- | --- |
| Testing | Add unit, integration, UI, and API testing appropriate to completed features. | Test results and issue log. |
| Documentation | Finalize technical documentation, setup guidance, model notes, and user-facing explanations. | Complete project documentation set. |
| Presentation | Prepare a product walkthrough, results summary, and demonstration narrative. | Presentation materials and demo plan. |
| Deployment | Configure a safe deployment target, environment variables, and baseline monitoring. | Deployment guide and deployed demonstration environment. |
